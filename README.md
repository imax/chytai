# Chytai

Читалка книжок у стилі Kindle, яка пояснює виділений текст за допомогою Claude прямо під час читання.

Виділяєш слово, фразу чи абзац, натискаєш «Пояснити», і пояснення з'являється саме в контексті цієї книжки. Модель бачить виділений фрагмент, кілька абзаців до і після, назву книжки й розділу.

Chytai має дві рівноправні версії з одним інтерфейсом:

- **Веб-версія (PWA)** для телефона й будь-якого браузера. Вона оптимізована під читання з телефона, і саме нею ми користуємося щодня. Працює на https://chytai.fly.dev.
- **Десктопна версія** для macOS (Electron), яка вміє також читати книжки з локальних папок та iCloud.

## Можливості

- **Типографіка як у Kindle:** шрифт Literata, вирівнювання по ширині, переноси, колонтитул із назвою книжки. У налаштуваннях можна вибрати шрифт і поля сторінки. Розмір шрифту (A− / A+) запам'ятовується для кожної книжки окремо.
- **Пояснення:** виділи текст і натисни **Пояснити** або **Спитати…**, щоб поставити своє питання. Пояснення короткі, наскільки дозволяє фрагмент; кнопка «Детальніше» під відповіддю розгортає його, а в полі нижче можна дописати уточнення. Пояснені місця підсвічуються в тексті, і тап по підсвітці відкриває відповідну картку.
- **Бібліотека:** зверху нещодавно відкриті книжки, найсвіжіші першими, нижче всі книжки за авторами, з пошуком і фільтром мови.
- **Позиція в кожній книжці** запам'ятовується окремо для кожного читача.
- **Виноски:** після переходу за посиланням типу [230] з'являється кнопка «← Назад», яка повертає туди, де читав.
- **PDF «Як книжка»:** читалка витягує текст із PDF, прибирає колонтитули й номери сторінок і показує його з тією самою типографікою, що й EPUB. Кнопка «Оригінал PDF» повертає оригінальну верстку.

## Веб-версія на телефоні

Сервер `server/index.js` віддає інтерфейс із `src/renderer/` і невеликий API, а `src/renderer/web-bridge.js` замінює місток Electron на HTTP-запити. Ключ Claude API лежить лише на сервері; телефон його ніколи не бачить. Бібліотека спільна для всієї родини, а позиції й налаштування в кожного свої (вхід за ім'ям і спільним паролем).

На iPhone відкрий адресу в Safari, увійди і додай на екран «Додому» (Поділитися → На Початковий екран), і далі Chytai відкривається як застосунок.

Як читати на телефоні:

- Під час читання панель кнопок схована, і текст займає весь екран. Тап по сторінці показує панель, прокрутка ховає її знову. Тему (світла, сепія, темна) перемикає кнопка ◐ на панелі.
- Книжка читається безперервною прокруткою. Якщо зручніше гортати сторінки (свайп або тап по краю), це вмикається в налаштуваннях.
- Виділяєш скільки треба (пояснення саме не стартує), потім тиснеш «Пояснити» в панельці внизу екрана. Пояснення відкриваються в нижній частині екрана і ховаються кнопкою «Сховати».
- Книжки додаються кнопкою «Додати книжку…» (EPUB і PDF). Інші формати спершу конвертуються на Mac через Calibre.

### Демо-режим для гостей

Посилання `/demo` (є також на сторінці входу) відкриває читалку без пароля: одна демо-книжка, без завантажень і видалень, із денним лімітом пояснень, щоб ключ Claude не можна було вичерпати. Позиції та налаштування гостя живуть лише в пам'яті сервера.

- Вбудована демо-книжка: Остап Вишня, «Мисливські усмішки» разом із «Моєю автобіографією» (тексти з УкрЛіб, зібрані в EPUB) у `demo/`. Будь-який EPUB/PDF у `/data/demo` на томі має пріоритет над вбудованим.
- Член родини може вибрати іншу книжку з бібліотеки в налаштуваннях («Книжка для демо-режиму»); варто обирати лише те, що можна показувати публічно.
- Ліміти: `GUEST_EXPLAIN_LIMIT` пояснень на гостя за день (типово 15), `GUEST_EXPLAIN_TOTAL` на всіх гостей (типово 150); `GUEST_MODE=off` вимикає демо зовсім.

### Статистика для родини

Сторінка `/admin` (кнопка «Статистика» в налаштуваннях) показує, хто читає, скільки книжок у бібліотеці і скільки пояснень використано: сьогодні, за тиждень, усього, по днях і по моделях, із приблизною вартістю за тарифами API. Лічильники живуть у `state.json` (`stats`), гості на сторінку не потрапляють. День рахується за `STATS_TZ` (типово Europe/Kyiv).

### Запуск локально

```bash
cp .env.example .env   # ANTHROPIC_API_KEY, READER_PASSWORD, READER_SECRET
npm install
npm run web            # http://localhost:8080
```

### Деплой на Fly.io

Застосунок описано у `fly.toml` (книжки й позиції лежать на томі `/data`):

```bash
fly launch --copy-config --no-deploy   # один раз
fly secrets set ANTHROPIC_API_KEY=… READER_PASSWORD=… READER_SECRET=…
fly deploy
node scripts/upload-books.mjs https://chytai.fly.dev "~/Library/Mobile Documents/com~apple~CloudDocs/Books"
```

Машина засинає, коли нею ніхто не користується, і прокидається на перший запит за кілька секунд.

## Десктопна версія (macOS)

Потрібен Node.js 20 або новіший (`brew install node`, якщо його ще немає).

```bash
npm install
npm start
```

Ключ Claude API можна покласти у файл `.env` поруч із `package.json` (рядок `ANTHROPIC_API_KEY=sk-ant-…`) або вставити в налаштуваннях (⌘,), де він шифрується через Keychain macOS. Ключ із налаштувань має пріоритет. Створити ключ можна на https://platform.claude.com, розділ API Keys.

- **Бібліотека** (⌘L) показує книжки з папок бібліотеки. За замовчуванням це iCloud Drive → Books; «Додати папку…» додає інші. Книжки, що лежать лише в iCloud, завантажуються при відкритті.
- **Відкрити книжку:** «Відкрити», ⌘O або перетягнути файл у вікно.
- **Гортати:** стрілки ← →, пробіл або клік по краях сторінки.
- На компʼютері пояснення може з'являтися одразу після виділення (вмикається в налаштуваннях).
- ⌘E ховає або показує панель пояснень, ⌘, відкриває налаштування.

Збірка `.app`:

```bash
npm run dist
```

Готовий `.dmg` з'явиться в `dist/`. Застосунок не підписаний, тож перший раз відкривай його через правий клік → «Відкрити».

## Модель

Пояснення робить одна модель, за замовчуванням `claude-opus-5-5` з effort `low`. У налаштуваннях можна вибрати `claude-sonnet-5-5` або `claude-haiku-5-5` (найдешевша). Для Opus і Sonnet увімкнено серверний fallback (`fallbacks: "default"`): якщо модель відмовиться відповідати на фрагмент, запит автоматично повториться на іншій моделі.

## Формати

EPUB і PDF відкриваються напряму. У PDF текст виділяється так само, а як контекст береться текст поточної сторінки й сусідніх. Скановані PDF без текстового шару пояснювати не вийде, бо там немає тексту для виділення. У десктопній версії MOBI, AZW, AZW3, FB2, DOCX, RTF, TXT та інші читалка сама конвертує в EPUB через Calibre, якщо він встановлений (`brew install --cask calibre` або calibre-ebook.com). Конвертована копія кешується, тож вдруге книжка відкривається одразу.

Книжки, куплені в Kindle Store, зазвичай захищені DRM. Calibre такі файли не конвертує, і читалка покаже про це повідомлення. Книжки без DRM (наприклад, з Gutenberg чи Standard Ebooks, або ті, де видавець вимкнув DRM) працюють.

## Структура

- `server/index.js` — веб-сервер: вхід, бібліотека, позиції й налаштування кожного читача, запити до Claude.
- `src/renderer/web-bridge.js` — місток веб-версії замість Electron.
- `src/renderer/` — спільний інтерфейс: `renderer.js` (читалка на epub.js і панель пояснень), `context.js` (вибирає текст навколо виділення), `library-view.js` (бібліотека), `pdf-view.js` і `pdf-reflow.js` (PDF), `search.js`, `style.css` (включно з мобільною версткою).
- `src/main.js`, `src/preload.js` — головний процес Electron і місток для десктопу.
- `src/ai.js` — запит до Claude API (промпт, модель, стрімінг).
- `src/library.js` — сканування папок і метадані книжок.
- `src/convert.js` — конвертація не-EPUB форматів через `ebook-convert` з Calibre.
- `scripts/upload-books.mjs` — завантаження книжок із папки до веб-бібліотеки.
- `scripts/move-to-chytai.sh` — разовий переїзд зі старого Fly-застосунку ai-reader-max на chytai.
- `build/icon.svg`, `build/icon.png` — іконка.
