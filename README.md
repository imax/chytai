# Chytai (AI Reader)

Десктопна читалка EPUB для macOS (у стилі Kindle for Mac), яка пояснює виділений текст за допомогою Claude прямо під час читання.

Виділяєш слово, фразу чи абзац, і праворуч з'являється пояснення саме в контексті цієї книжки: модель бачить виділений фрагмент, кілька абзаців до і після, назву книжки й розділу.

## Запуск

Потрібен Node.js 20 або новіший (`brew install node`, якщо його ще немає).

```bash
cd ai-reader
npm install
npm start
```

Ключ Claude API можна покласти у файл `.env` поруч із `package.json` (рядок `ANTHROPIC_API_KEY=sk-ant-…`) або вставити в налаштуваннях (⌘,), де він шифрується через Keychain macOS. Ключ із налаштувань має пріоритет. Створити ключ можна на https://platform.claude.com, розділ API Keys.

## Як користуватися

- **Бібліотека:** кнопка «Бібліотека» або ⌘L показує всі книжки з папок бібліотеки, згруповані за автором, з пошуком і фільтром мови. За замовчуванням це iCloud Drive → Books; «Додати папку…» додає інші. Назву й автора читалка бере з самого файлу (EPUB, FB2), а для файлів, що лежать лише в iCloud, з назви файлу; такі книжки завантажуються при відкритті.
- **Відкрити книжку:** кнопка «Відкрити», ⌘O або перетягнути `.epub` у вікно. Програма пам'ятає останню книжку та місце в кожній.
- **Гортати:** стрілки ← →, пробіл, або клік по краях сторінки. «Зміст» відкриває оглав.
- **Пояснення:** виділи текст, і пояснення з'явиться саме (це можна вимкнути в налаштуваннях). Над виділенням є панелька:
  - **Пояснити** — швидке пояснення (Claude Opus 5.5).
  - **Глибше** — розгорнутий розбір потужнішою моделлю (Claude Fable 5.1).
  - **Спитати…** — поставити своє питання про виділений фрагмент.
- Під кожним поясненням можна дописати уточнювальне питання. Пояснені місця підсвічуються в тексті; клік по підсвітці прокручує до відповідної картки.
- ⌘E ховає або показує панель пояснень, ⌘, відкриває налаштування (модель, мова пояснень, автопояснення).

## Налаштування моделей

| Режим | За замовчуванням | Альтернативи |
|---|---|---|
| Швидке пояснення | `claude-opus-5-5`, effort `low` | `claude-sonnet-5-5`, `claude-haiku-5-5` (найдешевша) |
| «Глибше» | `claude-fable-5-1`, effort `medium` | `claude-opus-5-5` |

Для Opus, Sonnet і Fable увімкнено серверний fallback (`fallbacks: "default"`): якщо модель відмовиться відповідати на фрагмент, запит автоматично повториться на іншій моделі.

## Версія для телефону (веб)

Та сама читалка працює в браузері на iPhone або Android: `server/index.js` віддає ті самі файли з `src/renderer/` і невеликий API, а `src/renderer/web-bridge.js` замінює місток Electron на HTTP-запити. Ключ Claude API лежить лише на сервері; телефон його ніколи не бачить. Бібліотека спільна для всієї родини, позиції в книжках у кожного свої (вхід за ім'ям і спільним паролем).

Локально:

```bash
cp .env.example .env   # ANTHROPIC_API_KEY, READER_PASSWORD, READER_SECRET
npm run web            # http://localhost:8080
```

На Fly.io (застосунок описано у `fly.toml`, дані на томі `/data`):

```bash
fly launch --copy-config --no-deploy   # один раз
fly secrets set ANTHROPIC_API_KEY=… READER_PASSWORD=… READER_SECRET=…
fly deploy
node scripts/upload-books.mjs https://<app>.fly.dev "~/Library/Mobile Documents/com~apple~CloudDocs/Books"
```

На iPhone відкрий адресу в Safari, увійди і додай на екран «Додому» (Поділитися → На Початковий екран): далі читалка відкривається як застосунок. Гортання: свайп або тап по краю сторінки; виділення тексту працює так само, пояснення з'являються в панелі знизу. У веб-версії книжки додаються кнопкою «Додати книжку…» (EPUB і PDF; інші формати спершу конвертує Mac через Calibre).

## Збірка .app

```bash
npm run dist
```

Готовий `.dmg` з'явиться в `dist/`. Застосунок не підписаний, тож перший раз відкривай його через правий клік → «Відкрити».

## Формати

EPUB і PDF відкриваються напряму. PDF за замовчуванням показується в режимі «Як книжка»: читалка витягує текст, прибирає колонтитули й номери сторінок, збирає абзаци й показує їх із тією самою типографікою, що й EPUB. Кнопка «Оригінал PDF» вгорі повертає оригінальну верстку (потрібно для книжок із формулами, таблицями чи ілюстраціями). У PDF текст виділяється так само, а як контекст береться текст поточної сторінки й сусідніх. Скановані PDF без текстового шару пояснювати не вийде, бо там немає тексту для виділення. MOBI, AZW, AZW3, FB2, DOCX, RTF, TXT та інші читалка сама конвертує в EPUB через Calibre, якщо він встановлений (`brew install --cask calibre` або calibre-ebook.com). Конвертована копія кешується, тож вдруге книжка відкривається одразу.

Книжки, куплені в Kindle Store, зазвичай захищені DRM. Calibre такі файли не конвертує, і читалка покаже про це повідомлення. Книжки без DRM (наприклад, з Gutenberg чи Standard Ebooks, або ті, де видавець вимкнув DRM) працюють.

## Структура

- `build/icon.svg`, `build/icon.png` — іконка застосунку (PNG рендериться з SVG).
- `src/renderer/pdf-reflow.js` — перекладка PDF у текст із типографікою читалки (режим «Як книжка»).
- `src/main.js` — головний процес Electron: вікно, меню, файли, налаштування, ключ API.
- `server/index.js`, `src/renderer/web-bridge.js` — веб-версія для телефону: сервер з API та місток замість Electron.
- `scripts/upload-books.mjs` — завантаження книжок із папки до веб-бібліотеки.
- `src/renderer/pdf-view.js` — перегляд PDF на pdf.js.
- `src/library.js`, `src/renderer/library-view.js` — бібліотека: сканування папок, метадані, екран зі списком.
- `src/convert.js` — конвертація не-EPUB форматів через `ebook-convert` з Calibre.
- `src/ai.js` — запит до Claude API (промпт, вибір моделі, стрімінг).
- `src/preload.js` — безпечний міст між сторінкою і головним процесом.
- `src/renderer/` — інтерфейс: `renderer.js` (читалка на epub.js і панель пояснень), `context.js` (вибирає текст навколо виділення), `style.css`.
